# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Lively Photos Director and its users seriously.

If you discover a security issue or vulnerability (such as prompt-injection risks, malicious script execution vulnerabilities, or data leakage in distribution pipelines):

1. **Do not create a public GitHub issue.**
2. Please report it privately to the maintainer via GitHub Security Advisories or by emailing `mamdouh.aboammar@gmail.com`.
3. Include detailed steps to reproduce the vulnerability.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a patch.
